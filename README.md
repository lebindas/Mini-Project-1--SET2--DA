                                                         # Spotify User Churn and Listening Analytics Dashboard
                                                         
## Project Overview

This project uses Microsoft Power BI to analyze Spotify user data, subscription patterns, listening behaviour, and customer churn. The project includes three interactive dashboards to understand user engagement and identify customer churn patterns.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX

## Dashboard 1: Spotify User Overview

- Total users
- Premium users
- User churn rate
- Subscription distribution
- Users by music genre
- Average daily listening by genre

## Dashboard 2: Customer Churn Analysis

- Total churned users
- Active users
- Average days since last login
- Churned vs active users
- Churn by subscription type
- User churn by days since last login

## Dashboard 3: Spotify Listening Analytics

- Total users
- Average daily listening minutes
- Average skips per day
- Total playlists
- Listening time vs skips
- Users by country using treemap and map visualizations

## Key Insights

- Total users: 1,000
- Premium users: 617
- Free users: 383
- Churned users: 186
- Active users: 814
- User churn rate: 18.6%
- Average daily listening: 97.44 minutes
- Average skips per day: 4.63
